# DeutschFun 🇩🇪 Android

هذا مشروع Android حقيقي يغلّف نسخة DeutschFun الحالية داخل WebView مع الحفاظ على ملف التطبيق التعليمي الأصلي.

## البناء
- افتح المشروع في Android Studio.
- انتظر مزامنة Gradle.
- Build > Build APK(s).
- ثبّت APK على هاتف Android.

## ملاحظات
التطبيق يحتاج اتصال إنترنت لبعض الموارد الموجودة داخل صفحة HTML الحالية مثل Tailwind CDN وGoogle Fonts وFont Awesome. بيانات التقدم المحلية تستخدم localStorage داخل WebView.
