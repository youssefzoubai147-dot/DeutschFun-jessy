# بناء APK من الهاتف عبر GitHub Actions

1. ارفع هذا المشروع إلى مستودع GitHub جديد.
2. اجعل اسم الفرع `main`.
3. افتح تبويب **Actions**.
4. اختر **Build DeutschFun APK** ثم **Run workflow**.
5. بعد نجاح البناء، افتح نتيجة التشغيل ثم قسم **Artifacts**.
6. حمّل `DeutschFun-debug-apk` واستخرج ملف APK.
